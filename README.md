# Mariette Bondey Hair Website

A responsive one-page website created with HTML, CSS, and JavaScript.

## Files
- `index.html` — page structure and content
- `styles.css` — design, layout, responsive styling
- `script.js` — mobile navigation, portfolio filtering, service modal, and demo booking form

## How to open
Open `index.html` in any browser.

## Customize before publishing
1. Replace the gallery placeholders with Mariette's real hairstyle photos.
2. Add the salon phone number, email, location, business hours, and social media.
3. Add actual service prices and durations.
4. Replace the sample testimonial with real client feedback.
5. Connect the booking form to a service such as Formspree, Calendly, Square Appointments, Fresha, or another booking platform.
6. Publish with GitHub Pages, Cloudflare Pages, Netlify, or another web host.

## Adding a real image
Replace a placeholder such as:

```html
<div class="image-placeholder"><span>Knotless braids</span></div>
```

with:

```html
<img src="images/knotless-braids.jpg" alt="Knotless braids styled by Mariette Bondey">
```

Then place the image inside an `images` folder.
